# The Handbook

Working title: **The Forbidden Knowledge Bible: A Complete Codex of Ancient Knowledge, Lost Etymology, Cosmic Systems, Forgotten Technologies, Hidden Source Trails, and Modern Science Bridges**

Short title: **The Handbook**

This folder is the GitHub manuscript and research workspace for the book. It is designed as a continuity archive: a durable knowledge-preservation project that teaches readers how to think, verify, trace sources, evaluate claims, and move responsibly from evidence to interpretation.

## Core principle

> This is a map of knowledge, not a claim of final truth.

The book should preserve:

- how knowledge is formed
- how source trails are followed
- how claims are verified
- how speculation is separated from evidence
- how ancient symbolic, practical, textual, architectural, ritual, astronomical, mathematical, and technical knowledge can be studied without exaggeration

## Repository structure

```text
the-handbook/
  00_project_control/     book rules, prompts, blueprint, evidence system
  01_manuscript/          chapter drafts and publish-ready prose
  02_source_tracking/     source trail trackers and claim logs
  03_visuals/             plate manifests and image plans
  04_build_pipeline/      export, formatting, and production notes
  05_logs/                build logs and changelog
```

## Working rule

Every chapter should separate:

1. evidence
2. interpretation
3. symbolic reading
4. later textual memory
5. modern speculation
